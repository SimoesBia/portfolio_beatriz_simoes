# Portfólio | Beatriz S. 🪻

Portfólio em React, TypeScript, Vite e Tailwind CSS, com identidade visual lilás minimalista. Inclui foto, trajetória profissional, formação e projetos reais.

## Rodar localmente (CMD do VS Code)

```cmd
npm install
npm run dev
```

Acesse o endereço informado pelo Vite, geralmente `http://localhost:5173`.

## Testar build

```cmd
npm run build
npm run preview
```

## Personalização

- `src/config.ts`: nome, links, e-mail, currículo e projetos.
- `public/beatriz-retrato.webp`: foto de apresentação.
- `src/style.css`: estilos e responsividade.
- `src/main.tsx`: seções e componentes.
- Currículo: ainda não está integrado porque a versão fornecida está desatualizada. Quando tiver uma nova versão, salve `public/curriculo.pdf` e configure `resume: '/curriculo.pdf'`.

**Privacidade:** o projeto Gestão Escolar é citado como experiência real, sem expor repositório privado, código ou dados da escola. Não adicione material de clientes sem autorização.

**Visual dos projetos:** as imagens dos cards são ilustrações estilizadas, não capturas de tela reais. Substitua por prints aprovados se quiser demonstrar a interface.

## Atualizar seu projeto existente

Faça uma cópia da pasta atual antes de substituir os arquivos. Extraia o ZIP e copie os arquivos da pasta `beatriz-portfolio` para a pasta do seu portfólio. Rode `npm install` e `npm run dev`.

## Publicação

Você pode publicar o repositório no GitHub e importar o projeto no Vercel. A instalação e o build podem usar os comandos `npm install` e `npm run build`, respectivamente. Confira os limites vigentes do plano gratuito.


## Galeria de projetos (V3)

As artes ilustradas dos cards foram preservadas. As capturas reais aparecem **abaixo dos cards** da Lily Tasks, Gestão Escolar e Court of Books. Clique em uma miniatura para ampliar e use as setas para navegar.

As capturas de Gestão Escolar receberam desfoque em áreas com identificação institucional e dados operacionais; revise-as antes de publicar, já que o sistema é privado e utilizado por uma escola.

Imagens em `public/screenshots/`; galeria em `src/main.tsx` e estilos em `src/style.css`.


## Galerias de projetos (versão final)

As sete galerias exibem imagens estáticas, sem ampliação, modal ou botão de zoom. As imagens de Product Data Pipeline e Customer Messaging ETL são projeções visuais ilustrativas, com dados fictícios, identificadas nas respectivas legendas. As demais imagens são capturas fornecidas pela autora.
